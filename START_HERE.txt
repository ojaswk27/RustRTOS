📊 WHAT HAPPENS DURING TRAINING

Stage 1 (1M steps)
   Learn basic urgency on feasible tasksets (U=0.60-0.95)
   ✓ Saves checkpoint at step_100000, step_200000, ..., step_1000000

Stage 2 (1.5M steps)
   Learn tradeoffs on mixed overload (U=0.85-1.15)
   ✓ Plus 15% WCET variability
   ✓ Checkpoints at step_1100000, step_1200000, ..., step_2500000

Stage 3 (1.5M steps)
   Learn aggressive prioritization (U=1.10-1.35)
   ✓ Plus 30% WCET variability
   ✓ Checkpoints at step_2600000, step_2700000, ..., step_4000000

Stage 4 (1M steps)
   Specialize on extreme stress (U=1.25-1.50)
   ✓ Plus 40% WCET variability
   ✓ Checkpoints at step_4100000, step_4200000, ..., step_5000000

FINAL: Evaluate on all tasksets + all schedulers
   Output:
   - ppo_rtos_extended_model/ppo_rtos_extended.zip
   - training_extended.json (metrics)
   - comparison_extended.json (results)
   - comparison_extended.png (visualization)

⚠️  TROUBLESHOOTING
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Q: Script won't start
A: $ uv sync --refresh

Q: Out of memory
A: Edit train_extended.py, change batch_size from 64 to 32

Q: Checkpoint corrupted
A: $ rm -rf checkpoints/step_500000/
   $ uv run python train_extended.py --resume  # Will load step_400000

Q: Too slow?
A: Normal. 5M steps on CPU = 8-12 hours. Can split with --resume.
